    How it's built

    Four pieces, all written from scratch. No pretrained weights, no Hugging Face, no ONNX, no WebGPU library: just PyTorch tensors for training and plain TypeScript for inference.

      1 · Tokenizer

      A byte-level BPE tokenizer trained on the stories. It starts with the 256 possible bytes and learns 3,839 merges, pair by pair, until common words like ·once and ·princess are single tokens. The browser runs an exact port of it.

      2 · Transformer

      The same design as Meta's Llama, scaled down: rotary position embeddings, RMSNorm, SwiGLU feed-forward layers, and an output layer tied to the input embeddings. About 150 lines of PyTorch.

      3 · Training

      Trained from random numbers on a laptop RTX 3070 Ti, using AdamW with warmup and cosine decay in bfloat16. Every 500 steps it saves a resumable checkpoint, so a closed lid doesn't cost a whole run.

      4 · Inference engine

      A from-scratch TypeScript forward pass with a key/value cache, running in a Web Worker. Weights ship as int8 with a per-row scale, 4× smaller than float32. A test checks that its output matches PyTorch's.
